# EdgeOfClick

A team-made game created in Godot with GDScript during the 30-hour Paris-Saclay Code Game Jam. The project won second place.

## Run

**Windows build:** Run `EdgeOfClickFinal.exe` from the repository root.

**From the project:** Install Godot 4.5 or later, import `project.godot` in the Godot Project Manager, then run the project with **F5**.
